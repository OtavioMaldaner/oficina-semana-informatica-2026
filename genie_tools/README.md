`genie_tools` is a submodule of Databricks Tools designed to facilitate the extraction, creation, and bulk updating of Databricks Genie Spaces.

## Components

### `creator.py`
Contains the core logic for metadata manipulation and communication with the Databricks API.
- **`GenieMetadata`**: A data model that processes and standardizes the Genie payload (`raw_serialized_space`), sorting tables, columns, instructions, and questions alphanumerically. This ensures consistency and prevents unnecessary diffs when updating spaces, maintaining version stability.
- **`GenieCreator`**: A manager that uses the `WorkspaceClient` (Databricks SDK) to process a metadata queue. It automatically evaluates whether each space should be created or updated.

### `utils.py`
Contains utility functions focused on extracting and cleaning payloads.
- **`generate_metadata`**: Orchestrator function that takes an existing Genie Space by its ID and generates a Python script with ready-to-use metadata. It replaces static IDs with `uuid.uuid4().hex`, formats multiline texts using `textwrap.dedent`, and formats the output code using `black`.
- **`get_spaces_map`**: Maps all spaces in the workspace to optimize existence checks (creation vs. update).

## How to Use

### 1. Exporting an Existing Genie
If you manually created a Genie space via the Databricks UI and want to turn it into code:

```python
from databricks.sdk import WorkspaceClient
from databricks_tools.genie_tools.utils import generate_metadata

client = WorkspaceClient()

generate_metadata(
    workspace_client=client,
    genie_resource_id="YOUR_GENIE_ID",
    metadata_getter_function_name="get_my_genie_metadata",
    path="metadata/my_genie.py" # Where the file will be saved
)
```

### 2. Creating or Updating Spaces via Code
After generating the metadata, you can import it and use `GenieCreator` to publish the changes.

```python
from databricks_tools.genie_tools.creator import GenieCreator, GenieMetadata
# Import the function generated by generate_metadata
from metadata.my_genie import get_my_genie_metadata

metadata_dict = get_my_genie_metadata()

metadata = GenieMetadata(
    title=metadata_dict["title"],
    description=metadata_dict["description"],
    raw_serialized_space=metadata_dict["serialized_space"]
)

creator = GenieCreator(warehouse_id="YOUR_SQL_WAREHOUSE_ID")
creator.add_metadata(metadata)

# Evaluates and executes creation or update
creator.create_or_update_all_genies()
```
